# Video script — what to SAY and what to SHOW

**Length:** ~5–6 minutes (max 10)  
**Before Record:** Redis + Flask + Celery worker running, browser open at login page.

---

## 0:00–0:30 · INTRO

**Show:** Your face (optional) + app login page  

**Speak:**
> “Hello everyone. My name is [YOUR NAME]. My roll number is [YOUR ROLL].  
> This is my Modern Application Development Two project — Trekking Management Application Version Two.  
> The app has three roles: Admin, Trek Staff, and User or Trekker.  
> I will first explain my approach, then give a live demo of the main features.”

---

## 0:30–1:00 · APPROACH

**Show:** Briefly open project files in VS Code / Codespaces:
1. `models.py`  
2. `app.py`  
3. `tasks.py`  
4. Back to browser  

**Speak:**
> “I approached the problem by first creating SQLite tables using Flask-SQLAlchemy models for User, Staff Profile, Trek, and Booking. The database is created automatically in code.  
> Admin is seeded programmatically, so there is no Admin registration.  
> Authentication uses JWT tokens with role-based access.  
> The UI is Vue.js with Bootstrap, and Jinja is only used for the entry page.  
> Redis is used for caching trek lists, and Celery is used for daily reminders, monthly HTML report, and CSV export.  
> Now I will start the live demo.”

- `exports/daily_reminders.txt`
- `exports/monthly_report.html`

**Speak:**
> “Daily reminder job sends reminders for upcoming treks with start date and trek details.

> Redis caching is also used for frequently accessed trek listings with expiry.”
